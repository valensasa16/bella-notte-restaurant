# Bella Notte | Italian Restaurant Website

A modern, elegant, and responsive Italian restaurant website built with Next.js, React, TypeScript, and Tailwind CSS.

**Live Demo:** https://bella-notte-restaurant.vercel.app/

## About the Project

Bella Notte is a fictional Italian restaurant website developed as a personal portfolio project to demonstrate frontend development, responsive web design, and interactive user interfaces.

The website combines a sophisticated black-and-gold visual identity with intuitive navigation and a mobile-friendly experience.

## Features

- **Responsive Design:** Optimized layouts for desktop and mobile devices.
- **Interactive Navigation:** Desktop navigation and a collapsible mobile menu.
- **Restaurant Menu:** Browse dishes using category filters, including Antipasti, Pasta, Main Courses, and Desserts.
- **Reservation Interface:** A demonstration booking form with date, time, and guest selection.
- **Restaurant Information:** Dedicated sections for the restaurant story, location, opening hours, and contact information.
- **Modern UI:** Elegant typography, food photography, and a consistent visual design.

## Getting Started

To run this project locally:

1. Clone the repository:

   `git clone https://github.com/valensasa16/bella-notte-restaurant.git`

2. Navigate to the project directory:

   `cd bella-notte-restaurant`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open http://localhost:3000 in your browser.

## Deployment

The application is deployed using Vercel and connected to GitHub for continuous deployment.

**Live Website:** https://bella-notte-restaurant.vercel.app/

## Project Scope

This website is a portfolio demonstration created for educational and professional development purposes.

Bella Notte is a fictional restaurant. The reservation form demonstrates the user interface and does not process real reservations.
